## 2. Timing and surcharge

The declaration may be filed with the application or postponed until no later than the date the issue fee is paid, provided an ADS naming the inventor is filed at filing (37 CFR 1.53(f)(3)). Filing it with the application avoids the late-declaration surcharge (37 CFR 1.16(f)). Recommended: execute and file with the application.
