## WHAT IS CLAIMED IS:

**1.** A computer-implemented method of guiding a user through a task in a target application, the method comprising:

receiving, at a guidance client executing on a user device having a display on which the target application is rendered, a user-stated goal;

obtaining an ordered plan comprising a plurality of steps generated by a planning machine-learning model from the user-stated goal, each step comprising an instruction and a visible-when-done condition, the visible-when-done condition being generated by the planning machine-learning model together with the plan and describing display content that will be present on the display when the step has been performed;

capturing, by the guidance client, a first frame of the display;

generating, on the user device, a redacted first frame by recognizing text within the first frame, determining, by a policy engine executing on the user device, that at least one recognized text region contains sensitive information, and masking the at least one recognized text region in the first frame before the first frame is transmitted from the user device;

transmitting, from the user device to a guidance server, the redacted first frame and the plan including a status of each step;

receiving, at the guidance client, a navigation record generated using a machine-learning model having image-understanding capability from the redacted first frame and the plan, the navigation record identifying (i) each step of the plan whose visible-when-done condition is shown satisfied in the redacted first frame, (ii) a single current step, and (iii) a single instruction for the current step that references display content visible in the redacted first frame;

presenting the single instruction on the display, wherein the guidance client is configured to present the single instruction without injecting any input event into the target application, such that performance of the single instruction is reserved to the user;

capturing, by the guidance client after the presenting, a second frame of the display, generating a redacted second frame on the user device, and transmitting the redacted second frame to the guidance server;

advancing the current step to a subsequent step of the plan only when a second navigation record generated from the redacted second frame and the plan identifies the visible-when-done condition of the current step as satisfied by display content present in the redacted second frame, and otherwise presenting a corrective instruction for the current step derived from the second navigation record; and

in response to the second navigation record identifying the visible-when-done condition of the current step as satisfied, retaining the redacted second frame, as generated on the user device for the transmitting, as evidence of the current step, such that no frame other than the redacted second frame is transmitted or stored as the evidence.

**2.** The method of claim 1, wherein the navigation record and the second navigation record each further comprise an observation describing content of the redacted frame from which that navigation record was generated and a flag that is non-empty when that redacted frame shows an error or an incorrect value, and wherein the corrective instruction is derived from the flag of the second navigation record.

**A1 (II-1, method).** A computer-implemented method of generating a guidance plan for a human performer, comprising:

receiving a goal statement and an application identifier from a requesting user, and an environment description of the requesting user's session comprising at least one of a jurisdiction, a list of named software and a manual-versus-software indicator;

computing a goal signature of the goal statement, the goal signature being an ordered token set produced by lowercasing the goal statement, removing email addresses, uniform resource locators and possessives, removing tokens that are purely numeric or version-like, removing stop words, applying singularization and removing duplicate tokens;

for each workflow template in a store scoped to a holder of the requesting user, each workflow template comprising a stored goal signature, a stored application key, a stored environment record and ordered steps, computing (i) a goal similarity equal to a mean of a Jaccard index and an overlap coefficient of the goal signature and the stored goal signature, (ii) an application similarity that treats the application identifier and the stored application key as matching when they are equal or when one is a token subset of the other, and (iii) an environment compatibility score that is reduced by each contradiction between the environment description and the stored environment record, a contradiction being a differing jurisdiction, a disjoint list of named software or a conflicting manual-versus-software indicator, and an attribute absent from the environment description never contradicting;

forming a weighted combination of the goal similarity, the application similarity and the environment compatibility score;

classifying a best-scoring workflow template into a serving tier only when the weighted combination meets a first floor, the application similarity indicates a match, no contradiction exists and the environment compatibility score meets an environment floor; into a seeding tier when the weighted combination meets a second floor lower than the first floor and the best-scoring workflow template was not classified into the serving tier; and otherwise withholding the best-scoring workflow template; and

generating the guidance plan by adapting the ordered steps of a serving-tier workflow template to the environment description in a single adaptation pass of a language model, the single adaptation pass comprising supplying the serving-tier workflow template to the language model together with a directive to follow the serving-tier workflow template as the backbone of the guidance plan and to adapt it only where the environment description differs from the stored environment record, by supplying a seeding-tier workflow template to a planning language model as context for a planning pass, or, when the best-scoring workflow template is withheld, by the planning pass without any workflow template, wherein each step of the guidance plan is presented to the human performer one step at a time and is verified against a captured frame of the human performer's display before a subsequent step is presented.
